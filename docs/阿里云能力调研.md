# 阿里云能力调研报告（ECS 自建数据库场景）

> 调研日期：2026-08-06
> 目的：确认 Agent 接入与管控 ECS 上自建数据库（PG/MySQL）时，阿里云能提供哪些 API / 能力
> 状态：能力存在性已确认；对 ECS 自建实例的实际可用性标注「待验证」

## 1. 结论速览

**可行。** 阿里云为"ECS 自建数据库"场景提供了完整的 Agent 接入通道，覆盖四个环节：

| 环节 | 能力 | 状态 |
|---|---|---|
| 感知（指标/告警） | 云监控 CMS + DAS 异常检测 | ✅ API 已确认 |
| 感知（日志） | SLS + LoongCollector | ✅ API 已确认 |
| 诊断 | DAS（诊断报告/锁分析/慢日志） | ⚠️ 对自建库的完整可用性待验证 |
| 执行 | 云助手 RunCommand | ✅ API 已确认 |
| 权限 | RAM/STS 临时凭证 | ✅ API 已确认 |

**最大发现**：DAS 官方支持「接入阿里云 ECS 自建数据库实例」（直连接入），且提供完整 OpenAPI。这意味着诊断环节可以大量复用阿里云的数据库自治能力，而不必从零自建。

## 2. 能力清单

### 2.1 云助手（执行通道）★ 核心

Agent 对 ECS 上数据库执行操作（改参数、kill 会话、DDL、重启）的官方通道。

- **RunCommand**：在一台或多台 ECS 上创建并执行命令，支持 Shell / PowerShell / Bat
- 支持定时执行、自定义参数、实例内容器执行
- **InvokeCommand**：执行已有命令
- **DescribeInvocations / DescribeInvocationResults**：查询执行信息与结果
- **执行记录保留 30 天，上限 1 万条**（天然审计能力）
- 支持事件订阅（EventBridge）获取任务结果，无需轮询
- 超时范围 10～86400 秒（默认 60 秒）

**对方案的意义**：executor Agent 不直接 SSH，而是通过云助手执行——所有操作天然有执行记录、可审计、可查询结果。

### 2.2 DAS 数据库自治服务（诊断通道）★ 最大发现

官方明确支持接入「阿里云 ECS 自建数据库实例」（控制台 → 智能运维中心 → 快速实例接入 → 阿里云 ECS 自建数据库 → 直连接入）。

产品定位：基于机器学习和专家经验的数据库"自动驾驶"服务，融合千问大模型与运维 SOP 体系。

**已确认的 OpenAPI**（均带 RAM 权限点，如 `hdm:GetAutonomousNotifyEventsInRange`）：

| API | 用途 |
|---|---|
| GetAutonomousNotifyEventsInRange | 查询异常检测通知事件（Notice/Optimization/Warn/Critical 四级） |
| GetAutonomousNotifyEventContent | 单个自治事件详情 |
| CreateDiagnosticReport / DescribeDiagnosticReportList | 创建/查询诊断报告 |
| GetDBInstanceConnectivityDiagnosis | 连通性诊断 |
| GetDeadLockDetailList | 死锁详情 |
| GetAsyncErrorRequestStatResult | SQL 执行错误统计（SQL 洞察） |
| 慢日志查询 API | 慢 SQL 记录查询，支持全局慢日志多实例分组 |

**产品能力**（控制台侧，API 覆盖度待验证）：7x24 机器学习异常检测（覆盖监控指标、SQL、日志、锁、运维事件）、会话管理、锁分析（元数据锁/InnoDB 锁等待/死锁）、SQL 优化、安全审计。

### 2.3 云监控 CMS（指标/告警通道）

- **DescribeMetricList / DescribeMetricData**：查询 ECS 及云产品监控数据
- **DescribeAlertLogList / DescribeAlertLogCount**：查询报警历史
- 完整告警规则管理 API
- ECS 基础指标（CPU/内存/磁盘/网络）免安装自动采集；自定义指标可通过插件上报

### 2.4 SLS 日志服务（日志通道）

- **LoongCollector**：采集 ECS 上的日志（数据库日志、系统日志）
- **GetLogs / GetLogsV2**：查询日志，支持 SQL 式分析
- 可配置日志告警

### 2.5 RAM / STS（权限通道）★ JIT 权限的云侧底座

- **AssumeRole**：获取扮演 RAM 角色的临时凭证（STS Token），可设过期时间
- RAM 策略细粒度授权（到 API 级，如 `hdm:GetAutonomousNotifyEventsInRange`、`ecs:RunCommand`）
- **与 Higress allowedConsumers 形成双层 JIT**：网关层控制哪个 Agent 能调哪个工具，STS 层控制凭证有效期与权限范围

### 2.6 官方云 Skills

- **alibabacloud-ecs-troubleshoot-skills**（GitHub 开源）：ECS Linux 排查（SSH/网络/磁盘/性能/宕机）+ 安全检测，依赖 aliyun CLI，默认只读/诊断权限
- **alibabacloud-cms-manage**：云监控告警管理
- Skills 门户「迁移与运维管理」分类有 11 个 Skills，具体清单待逐一核对

## 3. 与 Agent 设计的映射

| Agent | 依赖的阿里云能力 |
|---|---|
| db-oncall-manager（告警接入） | CMS 告警 API + DAS 异常事件 API（ML 检测优于规则告警） |
| db-diagnostician（根因定位） | DAS 诊断报告/锁分析/慢日志 + CMS 指标 + SLS 日志 |
| db-planner（预案生成） | 不直接依赖云 API（LLM + 知识库） |
| db-executor（执行） | 云助手 RunCommand（执行通道）+ STS（临时凭证） |
| db-retrospector（复盘） | 云助手执行记录（30 天）+ DAS 诊断报告归档 |

## 4. 待验证清单 ★（决定是否真的有效）

| # | 待验证项 | 为什么关键 | 验证方式 |
|---|---|---|---|
| 1 | **DAS 接入 ECS 自建库后，异常检测/诊断报告 API 是否对自建实例生效** | API 文档示例多以 RDS/PolarDB 为例，自建库能力范围可能收窄 | 控制台接入一台自建库，触发异常，查 GetAutonomousNotifyEventsInRange |
| 2 | **DAS 会话管理（kill 会话）对自建库是否可用、有无 API** | kill 会话是 L1 止血的核心动作 | 控制台会话管理页 + OpenAPI Explorer 检索 |
| 3 | **DAS 接入自建库的数据采集方式与延迟** | 决定诊断时效性 | 接入后观察指标刷新频率 |
| 4 | **云助手对数据库长命令的支持**（如大表 DDL 可能超 24h） | 执行通道的边界 | 实测长命令 |
| 5 | **aliyun CLI 在 AgentTeams Worker 容器内的可用性** | 官方 Skills 依赖它 | Worker 内安装实测 |
| 6 | **CMS 自定义指标插件对数据库进程级指标的覆盖** | 数据库内部指标（连接数/缓冲池）需自建采集 | 实测插件上报 |

## 5. 建议的验证顺序

1. **半天可完成**：#1 + #2（在 DAS 控制台接入一台 ECS 自建 PG/MySQL，把异常检测和会话管理摸一遍）——这两项直接决定 diagnostician 和止血环节的设计
2. **需要部署后验证**：#3～#6（等 ECS 数据库环境就绪）

## 6. 对方案的影响

- **诊断环节大幅简化**：diagnostician 不必自建全部诊断逻辑，优先调 DAS；自建能力（如执行计划基线比对）作为 DAS 的补充
- **止血环节有了官方通道**：kill 会话/限流如果 DAS 提供 API，止血可全自动化；否则走云助手执行 SQL
- **执行环节确定走云助手**：审计、结果查询、事件订阅都是白送的
- **JIT 权限升级为双层**：Higress（网关层）+ STS（云凭证层），两层都有秒级吊销能力
